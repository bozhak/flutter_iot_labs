## Flutter Laboratory Works

Цей репозиторій містить **5 лабораторних робіт з Flutter**, виконаних у межах навчального курсу з розробки мобільних застосунків.

Кожна лабораторна робота є окремим Flutter-проєктом і демонструє основні можливості фреймворку, зокрема:

* створення інтерфейсу користувача;
* роботу з віджетами;
* обробку введення користувача;
* керування станом застосунку;
* базову логіку взаємодії між компонентами.

Репозиторій може бути використаний як навчальний матеріал або як приклад для подальшого вивчення та розробки Flutter-застосунків.
